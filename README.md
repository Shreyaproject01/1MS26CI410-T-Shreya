# Champion–Challenger Sentiment Classification with Hugging Face and MLflow

## 1. Task and models
This individual mini-project compares two pretrained Hugging Face sentiment-classification models on the same labelled movie-review evaluation inputs.

- **Task:** Binary sentiment classification (positive = 1, negative = 0)
- **Evaluation file:** `data/eval_inputs.csv` (20 labelled sample reviews)
- **New data:** `data/new_data.csv` (8 different reviews, not in the evaluation set)
- **Model A (current Champion):** `distilbert/distilbert-base-uncased-finetuned-sst-2-english`
- **Model B (Challenger):** `textattack/bert-base-uncased-SST-2`

## 2. Champion rule (defined before the final run)
Primary metric is **F1-score**, where higher is better. Model B replaces Model A only if its F1-score is at least 0.01 (one percentage point) higher. If the absolute F1 difference is below 0.01, the faster model is preferred. Otherwise Model A remains Champion. Accuracy, precision, recall and inference latency are also reported. This rule is fixed before looking at the final results.

## 4. How to run (Windows / VS Code)
Install Python 3.10 or 3.11 and Git. Open this folder in VS Code, then open Terminal.

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Start MLflow tracking server in **Terminal 1**:
```powershell
mlflow server --host 127.0.0.1 --port 5000
```
Keep this terminal running. Open `http://127.0.0.1:5000` in a browser.

In **Terminal 2**, run:
```powershell
python evaluate.py
python register_champion.py
python predict_from_mlflow.py
```

The first evaluation downloads both Hugging Face models. This may take time and needs an internet connection. CPU execution is supported but can be slow. The MLflow tracking server must remain running for all three scripts.

If needed, set your USN before running (PowerShell):
```powershell
$env:STUDENT_USN="YOUR_USN"
```

**Important:** Scores and the winning model are generated by running the real pretrained models. Do not copy invented scores into your report. Use the values in `outputs/metrics_summary.json` after your own run.

## 7. Limitations and declaration
The evaluation dataset is a small, manually prepared sample and may not represent all movie-review language. Both models are pretrained models from Hugging Face; first-time downloads require internet. Inference is configured for CPU.
